2 ЗАВДАННЯ
Метою роботи є набуття практичних навичок роботи з командами обробки текстової інформації, керування стандартними потоками введення-виведення та використання фільтрів в ОС Unix. Основні завдання:
	реалізація пошуку файлів за заданими критеріями за допомогою утиліти find.
	фільтрація та перетворення текстового вмісту за допомогою команд grep, awk, sed, sort.
	організація складної обробки даних через механізм конвеєрів (pipes).
	забезпечення автоматизації процесу через написання Bash-скрипта з підтримкою виводу довідки та обробки помилок.


3. ОПИС ВИКОНАНОЇ РОБОТИ
У межах практичного заняття було розроблено програмний засіб на мові Bash для автоматизації обробки текстових лог-файлів та навігації у файловій системі.
Основні етапи реалізації:
1.	Обробка потоків: застосовано перенаправлення стандартного виводу (>) та додавання даних у файл (>>) для формування звітів про роботу скрипта.
2.	Фільтрація даних: використано утиліту grep для вибору рядків за регулярними виразами та awk для вибіркового виведення окремих колонок текстових даних.
3.	Конвеєрна обробка: для мінімізації використання тимчасових файлів реалізовано послідовну обробку даних через конвеєри (|), що дозволило ефективно поєднувати команди сортування (sort) та видалення дублікатів (uniq).
4.	Аргументи командного рядка: скрипт підтримує стандартні прапорці -h та --help, реалізовані через конструктор case.
Для написання коду та вирішення проблем із кодуванням символів (LF/CRLF) було залучено інструменти ШІ, що дозволило оптимізувати регулярні вирази для пошуку.


4. ВИСНОВКИ
Під час виконання практичного заняття було опановано інструментарій для ефективної роботи з текстовими масивами в Unix-подібних системах. Набуто навичок створення складних командних конструкцій, що базуються на взаємодії стандартних утиліт через потоки даних. Розроблений скрипт підтвердив ефективність використання мови Bash для завдань системного адміністрування та аналізу даних.

Приклади програмного коду
1  #!/bin/bash
2  
3  MAX_WIDTH=11
4  
5  for part in "Tiers" "Trunk" "Base"; do
6      if [ "$part" == "Tiers" ]; then
7          for (( tier=1; tier<=3; tier++ )); do
8              if [ $tier -eq 1 ]; then
9                  current_w=1
10             else
11                 current_w=3
12             fi
13             while [ $current_w -le 9 ]; do
14                 spaces=$(( (MAX_WIDTH - current_w) / 2 ))
15                 s_count=0
16                 while [ $s_count -lt $spaces ]; do
17                     echo -n " "
18                     s_count=$((s_count + 1))
19                 done
20                 h_count=0
21                 until [ $h_count -ge $current_w ]; do
22                     echo -n "#"
23                     h_count=$((h_count + 1))
24                 done
25                 echo ""
26                 current_w=$((current_w + 2))
27             done
28         done
29     elif [ "$part" == "Trunk" ]; then
30         t_rows=0
31         while [ $t_rows -lt 2 ]; do
32             for (( s=0; s<4; s++ )); do echo -n " "; done
33             for (( h=0; h<3; h++ )); do echo -n "#"; done
34             echo ""
35             t_rows=$((t_rows + 1))
36         done
37     else
38         b_count=0
39         until [ $b_count -ge $MAX_WIDTH ]; do
40             echo -n "#"
41             b_count=$((b_count + 1))
42         done
43         echo ""
44     fi
45 done
