2 ЗАВДАННЯ
Розробити Bash-скрипт, який виконує збір базової інформації про апаратне забезпечення (Hardware), операційну систему (System), мережеві інтерфейси (Network) та виводить її у стандартизованому форматі. Забезпечити підтримку параметрів командного рядка (-h|--help, -n num), запис результатів у файл за допомогою команди tee та автоматичну ротацію логів (архівування старих файлів).
3. ОПИС ВИКОНАНОЇ РОБОТИ
У межах лабораторної роботи розроблено скрипт для автоматизованого збору системної інформації з дотриманням строгих вимог до форматування.
Основні технічні рішення:
	Уникнення жорсткого кодування: дані отримуються динамічно за допомогою утиліт системного рівня (lscpu, dmidecode, ip, uname) та текстових фільтрів (grep, awk, cut).
	Незалежність від локалі: для забезпечення однакового формату часу Date та Unix Timestamp використано конструкцію LC_ALL=C date. Обидва значення генеруються за один виклик для точного збігу часу.
	Надійність у різних середовищах: реалізовано перевірки наявності команд та файлів. У разі відсутності утиліт (наприклад, у середовищі Windows Git Bash або на обмежених VPS) скрипт безпечно підставляє значення "Unknown" або "-/-", уникаючи помилок виконання.
	Робота з файлами: реалізовано механізм ротації логів. Вивід результату на екран та одночасний запис у файл забезпечено конвеєрним використанням команди tee.

4. ВИСНОВКИ
Під час виконання лабораторної роботи набуто практичних навичок отримання системної інформації засобами Bash. Опановано методи роботи з утилітами системного рівня, форматування складного текстового виводу, безпечної обробки відсутніх даних та одночасного запису інформації у файл.

Приклади програмного коду
1   #!/bin/bash
2   
3   # ==========================================
4   # 1. ЛОКАЛІЗАЦІЯ ТА НАЛАШТУВАННЯ
5   # ==========================================
6   if [[ "$LANG" == *"uk"* || "$LC_MESSAGES" == *"uk"* ]]; then
7       MSG_HELP="Використання: $0 [-h|--help] [-n num] [file]\n  -h, --help  Виведення довідки\n  -n num      Максимальна кількість архівних файлів\n  file        Файл для запису результату"
8       MSG_ERR_NUM="Помилка: параметр -n повинен бути цілим числом >= 1"
9       MSG_ERR_DIR="Помилка: не вдалося створити каталог"
10      MSG_ERR_PARAM="Помилка: невідомий параметр"
11  else
12      MSG_HELP="Usage: $0 [-h|--help] [-n num] [file]\n  -h, --help  Show help\n  -n num      Maximum number of archive files\n  file        File to write the result"
13      MSG_ERR_NUM="Error: parameter -n must be an integer >= 1"
14      MSG_ERR_DIR="Error: failed to create directory"
15      MSG_ERR_PARAM="Error: unknown parameter"
16  fi
17  
18  NUM_KEEP=0
19  TARGET_FILE="$HOME/log/task2.out"
20  
21  # ==========================================
22  # 2. ОБРОБКА ПАРАМЕТРІВ (CLI)
23  # ==========================================
24  while [[ $# -gt 0 ]]; do
25      case "$1" in
26          -h|--help)
27              echo -e "$MSG_HELP"
28              exit 0
29              ;;
30          -n)
31              shift
32              if [[ "$1" =~ ^[0-9]+$ ]] && [ "$1" -ge 1 ]; then
33                  NUM_KEEP=$1
34              else
35                  echo "$MSG_ERR_NUM" >&2
36                  exit 1
37              fi
38              ;;
39          -*)
40              echo "$MSG_ERR_PARAM: $1" >&2
41              exit 1
42              ;;
43          *)
44              TARGET_FILE="$1"
45              ;;
46      esac
47      shift
48  done
49  
50  # ==========================================
51  # 3. КЕРУВАННЯ КАТАЛОГАМИ ТА РОТАЦІЯ
52  # ==========================================
53  DIR_PATH=$(dirname "$TARGET_FILE")
54  if [ ! -d "$DIR_PATH" ]; then
55      mkdir -p "$DIR_PATH" || { echo "$MSG_ERR_DIR" >&2; exit 1; }
56  fi
57  
58  if [ -f "$TARGET_FILE" ]; then
59      CURRENT_DATE=$(date "+%Y%m%d")
60      LAST_IDX=$(ls "$DIR_PATH" 2>/dev/null | grep -E "$(basename "$TARGET_FILE")-$CURRENT_DATE-[0-9]{4}" | wc -l)
61      NEXT_IDX=$(printf "%04d" "$LAST_IDX")
62      mv "$TARGET_FILE" "$TARGET_FILE-$CURRENT_DATE-$NEXT_IDX"
63  fi
64  
65  if [ "$NUM_KEEP" -gt 0 ]; then
66      cd "$DIR_PATH" || exit 1
67      BASE_NAME=$(basename "$TARGET_FILE")
68      ls -t "$BASE_NAME"-* 2>/dev/null | tail -n +$((NUM_KEEP + 1)) | xargs -r rm -f
69      cd - >/dev/null || exit 1
70  fi
71  
72  # ==========================================
73  # 4. ФУНКЦІЯ ЗБОРУ ДАНИХ (ГЕНЕРАЦІЯ ЗВІТУ)
74  # ==========================================
75  generate_report() {
76      DATETIME=$(LC_ALL=C date "+%s|Date: %a, %d %b %Y %H:%M:%S %z")
77      TS=$(echo "$DATETIME" | cut -d'|' -f1)
78      D_STR=$(echo "$DATETIME" | cut -d'|' -f2)
79  
80      CPU_INFO=$(grep -m 1 'model name' /proc/cpuinfo 2>/dev/null | cut -d: -f2 | xargs)
81      [ -z "$CPU_INFO" ] && CPU_INFO="Unknown"
82  
83      RAM_KB=$(grep MemTotal /proc/meminfo 2>/dev/null | awk '{print $2}')
84      [ -n "$RAM_KB" ] && RAM_MB=$((RAM_KB / 1024)) || RAM_MB="Unknown"
85  
86      get_dmi() {
87          local val=$(dmidecode -s "$1" 2>/dev/null | grep -v '^#' | head -n 1 | xargs)
88          if [ -z "$val" ] && [ -f "$HOME/dmidecode.out" ]; then
89              if [ "$1" == "baseboard-manufacturer" ]; then val=$(grep -i "Manufacturer:" "$HOME/dmidecode.out" | head -n 1 | cut -d: -f2 | xargs); fi
90              if [ "$1" == "baseboard-product-name" ]; then val=$(grep -i "Product Name:" "$HOME/dmidecode.out" | head -n 1 | cut -d: -f2 | xargs); fi
91              if [ "$1" == "system-serial-number" ]; then val=$(grep -i "Serial Number:" "$HOME/dmidecode.out" | head -n 1 | cut -d: -f2 | xargs); fi
92          fi
93          [ -z "$val" ] && echo "Unknown" || echo "$val"
94      }
95  
96      MB_MANUF=$(get_dmi "baseboard-manufacturer")
97      MB_PROD=$(get_dmi "baseboard-product-name")
98      SYS_SERIAL=$(get_dmi "system-serial-number")
99  
100     OS_DIST=$(grep PRETTY_NAME /etc/os-release 2>/dev/null | cut -d= -f2 | tr -d '"')
101     [ -z "$OS_DIST" ] && OS_DIST="Unknown"
102 
103     KERNEL=$(uname -r 2>/dev/null || echo "Unknown")
104 
105     INSTALL_DATE=$(stat -c %w / 2>/dev/null)
106     [ "$INSTALL_DATE" == "-" ] || [ -z "$INSTALL_DATE" ] && INSTALL_DATE=$(stat -c %y / 2>/dev/null | cut -d. -f1)
107     [ -z "$INSTALL_DATE" ] && INSTALL_DATE="Unknown"
108 
109     H_NAME=$(hostname 2>/dev/null || echo "Unknown")
110     
111     UPTIME_VAL=$(uptime -p 2>/dev/null)
112     [ -z "$UPTIME_VAL" ] && UPTIME_VAL=$(uptime 2>/dev/null | xargs)
113     [ -z "$UPTIME_VAL" ] && UPTIME_VAL="Unknown"
114 
115     PROC_COUNT=$(ps -e --no-headers 2>/dev/null | wc -l)
116     [ "$PROC_COUNT" -eq 0 ] && PROC_COUNT=$(ls -d /proc/[0-9]* 2>/dev/null | wc -l)
117     [ "$PROC_COUNT" -eq 0 ] && PROC_COUNT="Unknown"
118 
119     USER_COUNT=$(who 2>/dev/null | wc -l)
120 
121     echo "$D_STR"
122     echo "Unix Timestamp: $TS"
123     echo "---- Hardware ----"
124     echo "CPU: \"$CPU_INFO\""
125     echo "RAM: $RAM_MB MB"
126     echo "Motherboard: \"$MB_MANUF\", \"$MB_PROD\""
127     echo "System Serial Number: $SYS_SERIAL"
128     echo "---- System ----"
129     echo "OS Distribution: \"$OS_DIST\""
130     echo "Kernel version: $KERNEL"
131     echo "Installation date: $INSTALL_DATE"
132     echo "Hostname: $H_NAME"
133     echo "Uptime: $UPTIME_VAL"
134     echo "Processes running: $PROC_COUNT"
135     echo "Users logged in: $USER_COUNT"
136     echo "---- Network ----"
137 
138     if command -v ip >/dev/null 2>&1; then
139         for iface in $(ip -o link show | awk -F': ' '{print $2}'); do
140             ip_info=$(ip -o -4 addr show dev "$iface" 2>/dev/null | awk '{print $4}')
141             if [ -z "$ip_info" ]; then
142                 echo "$iface: -/-"
143             else
144                 echo "$iface: $ip_info"
145             fi
146         done
147     else
148         echo "Unknown: -/-"
149     fi
150 
151     echo "----\"EOF\"----"
152 }
153 
154 # ==========================================
155 # 5. ВИКОНАННЯ ТА ЗАПИС У ФАЙЛ (tee)
156 # ==========================================
157 generate_report | tee "$TARGET_FILE"
158 
159 exit 0
Приклади запитів до сервісів ШІ
Запит: «Як одночасно вивести результат скрипта на екран і записати у файл?» Відповідь: Рекомендовано використати команду tee (наприклад, generate_report | tee "$TARGET_FILE"). 
Запит: «Як уникнути жорсткого кодування та залежності від локалі при генерації дати у Bash?» 
Відповідь: Використати LC_ALL=C date "+%s|Date: %a, %d %b %Y %H:%M:%S %z", а потім розділити отримане значення через команду cut.
