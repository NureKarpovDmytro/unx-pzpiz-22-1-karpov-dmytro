2 ЗАВДАННЯ
Розробити Bash-скрипт, який програмно виводить на екран текстове зображення «ялинки» заданого вигляду. У програмному коді обов’язково використати всі наведені керуючі конструкції:
1.	Умовний оператор: if ... then ... fi.
2.	Цикл із передумовою: while ... do ... done.
3.	Цикл із післяумовою: until ... do ... done.
4.	Цикл перебору списку: for ... in ... do ... done.
5.	Арифметичний цикл: for (( ... )); do ... done.
Формування зображення повинно виконуватись програмно за допомогою обчислення кількості пробілів та символів #. Скрипт має бути виконуваним файлом із правами доступу: виконання - для всіх користувачів, запис - лише для власника.


3. ОПИС ВИКОНАНОЇ РОБОТИ
Під час виконання практичної роботи було реалізовано алгоритм побудови геометричної фігури у середовищі командної оболонки Bash. Робота проводилася в операційній системі Windows із використанням емулятора Git Bash, що дозволило застосувати стандартні утиліти Unix без розгортання повноцінного дистрибутиву Linux.
Логіка програмного коду: 
Програма розділена на три логічні частини за допомогою циклу for..in: крона (яруси), стовбур та основа.
Крона: складається з трьох ярусів, що реалізовано через арифметичний цикл for (()). Для кожного ярусу обчислюється початкова ширина за допомогою оператора if.
Обчислення пробілів: для вирівнювання по центру використано формулу (MAX_WIDTH - поточна_ширина) / 2. Друк пробілів та символів # реалізовано за допомогою циклів while та until.
Стовбур та основа: стовбур малюється фіксованою шириною у два рядки, а основа — як фінальна горизонтальна лінія.
Налаштування прав доступу: встановлення прав доступу виконано командою chmod 755. Для збереження атрибутів у репозиторії GitHub використано команду git update-index --chmod=+x, що забезпечує коректне відображення прав файлу в системі контролю версій.

4. ВИСНОВКИ
У результаті виконання роботи було опановано практичні навички розробки сценаріїв мовою Bash. Вивчено особливості синтаксису керуючих конструкцій, зокрема відмінності між циклами з передумовою та післяумовою. Було продемонстровано можливість використання інструментів Git для керування атрибутами файлів Unix у середовищі Windows.

Приклади програмного коду
1  #!/bin/bash
2  
3  MAX_WIDTH=11
4  
5  for part in "Tiers" "Trunk" "Base"; do
6      if [ "$part" == "Tiers" ]; then
7          for (( tier=1; tier<=3; tier++ )); do
8              if [ $tier -eq 1 ]; then
9                  current_w=1
10             else
11                 current_w=3
12             fi
13             while [ $current_w -le 9 ]; do
14                 spaces=$(( (MAX_WIDTH - current_w) / 2 ))
15                 s_count=0
16                 while [ $s_count -lt $spaces ]; do
17                     echo -n " "
18                     s_count=$((s_count + 1))
19                 done
20                 h_count=0
21                 until [ $h_count -ge $current_w ]; do
22                     echo -n "#"
23                     h_count=$((h_count + 1))
24                 done
25                 echo ""
26                 current_w=$((current_w + 2))
27             done
28         done
29     elif [ "$part" == "Trunk" ]; then
30         t_rows=0
31         while [ $t_rows -lt 2 ]; do
32             for (( s=0; s<4; s++ )); do echo -n " "; done
33             for (( h=0; h<3; h++ )); do echo -n "#"; done
34             echo ""
35             t_rows=$((t_rows + 1))
36         done
37     else
38         b_count=0
39         until [ $b_count -ge $MAX_WIDTH ]; do
40             echo -n "#"
41             b_count=$((b_count + 1))
42         done
43         echo ""
44     fi
45 done
